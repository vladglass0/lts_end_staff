# LTS End Staff

Minecraft 1.20.1 Forge mod that adds an **Ender Staff** for instant teleportation.

## Features
- **Teleportation**: Right-click with the Ender Staff to teleport to the point you are looking at.
- **Configurable**: Adjust teleport distance and cooldown via the config file.
- **Visuals & Sound**: Includes Enderman teleport sounds and portal particles.
- **Safety**: Automatically resets fall distance upon teleportation to prevent fall damage.

## Configuration
The configuration file is located at `config/lts_end_staff-common.toml`.

| Setting | Default | Description |
|---------|---------|-------------|
| `teleportDistance` | 50.0 | Maximum distance you can teleport (1.0 - 500.0). |
| `teleportCooldown` | 40 | Cooldown in ticks (20 ticks = 1 second). |

## Localization
- English (US)
- Russian (RU)

## Creative Tab
The Ender Staff can be found in the **Tools & Utilities** creative tab.
